# ممیزی سایت tajrobeh.life · ۱۱ مهر ۱۴۰۵ (مرحلهٔ ۱، فقط خواندن)

منبع: کد مخزن (چهار بررسی موازی) و اندازه‌گیری زنده از GitHub Actions با کاربر claude-ops
(گردش‌کارهای `site-pull.yml` و `site-audit.yml`). هیچ چیزی روی سایت نوشته نشد.

راهنمای ستون «چه کسی»: **کد** = Claude Code در مخزن و انتشار از گیت‌هاب · **Cowork** = در پیشخوان وردپرس، GTM یا Search Console · **آرین** = روی سرور.
«تأیید» یعنی طبق قاعدهٔ پروژه پیش از اجرا تأیید یاسر لازم است.

## الف. دسترسی و همگام‌سازی

- محیط Claude به سرور سایت (IP ایرانی) نمی‌رسد؛ رانر GitHub می‌رسد (۲۰۰ در ۲ ثانیه). همهٔ کار سایت از Actions اجرا می‌شود.
- `new.tajrobeh.life` گواهی و میزبان ندارد (خطای TLS). کنار گذاشته شد.
- وضعیت زنده در `/site` کشیده شد: ۱۳۶ برگه، قالب‌ها، CSS سراسری، Yoast (`site/yoast.json`)، ریدایرکت‌ها (`site/redirects.json`)، افزونه‌ها (`site/platform.json`) و هش هر شیء (`site/state.json`).
- **تفاوت مخزن و سایت پیش از همگام‌سازی:** ۳۰ برگه بعد از ۹ مهر در وردپرس ویرایش شده بودند (کارت‌های پارتنر، صفحه‌های کشوری، مدرسه، رویدادها و …)، ۳ برگهٔ تازه در مخزن نبود (`/tests/migration/`، `/school/alumni/`، `/school/mentoring/`)، و قطعهٔ `tj-footer` فرق داشت. حالا همه با سایت یکی است.
- **استثنا:** برگهٔ ۵۰۳۸۸۶ (مینی‌اپ) در مخزن جدیدتر از سایت است و انتشارش با گردش کار بات (v169.4) است؛ دست نخورد.
- **اسنیپت‌های PHP (۲۶ فعال) بی پل قابل خواندن نیستند.** ۱۱ اسنیپت HTML/CSS/JS سراسری غیرمستقیم در HTML خانه سنجیده شد؛ ۱۰ تا یکی‌اند و ۵۰۵۲۸۱ (ویجت انتخاب تراپیست) کمی فرق دارد.
- وردپرس ۷٫۱٫۲ (تازه‌ترین) · قالب twentytwentyfive ۱٫۵ · ۷ افزونه · ریدایرکت‌ها ۲۱ از ۲۱ درست.

## پ. پل tj-ops (پیشنهاد، منتظر تأیید)

برگه‌ها، قالب‌ها، CSS سراسری و افزونه‌ها با REST خود وردپرس خوانده و نوشته می‌شوند. سه چیز راه REST ندارند: **اسنیپت‌های WPCode، متای خام Yoast و پاک کردن کش WP-Optimize**. برای انتشار خودکار این سه، پل `site/snippets/ops-bridge.php` پیشنهاد می‌شود:

- فقط کاربر claude-ops، فقط با Application Password (نه کوکی)، فقط با manage_options.
- فقط هفت کنش فهرست‌شده: خواندن وضعیت، نوشتن کد یک اسنیپت، ساخت اسنیپت غیرفعال، روشن یا خاموش کردن اسنیپت، نوشتن متای Yoast، پاک کردن کش، برگرداندن نسخهٔ قبل.
- هر فراخوانی (موفق یا رد) با زمان، مسیر، نتیجه و IP ثبت می‌شود؛ ۵ نسخهٔ قبلی هر شیء نگه داشته می‌شود؛ نوشتن فقط وقتی که هش زنده با انتظار یکی باشد؛ کد PHP پیش از ذخیره از نظر نحوی سنجیده می‌شود.
- **ریسک:** هر کس رمز claude-ops را داشته باشد، از این پل می‌تواند کد PHP روی سایت اجرا کند؛ یعنی هم‌ارز مدیر کامل است (البته هر مدیری از خود WPCode هم همین توان را دارد). رمز فقط در GitHub Secrets است. پیشنهاد: Application Password جدا برای هر کاربرد و چرخش فصلی.
- **محدودیت:** WPCode Lite نمی‌تواند اسنیپت را فقط روی یک برگه اجرا کند. پس «تست اسنیپت روی برگهٔ آزمایشی» فقط برای اسنیپتی شدنی است که خودش به برگهٔ خاصی محدود است. برای بقیه، روند: ساخت غیرفعال، روشن کردن، تست دود فوری، و خاموش شدن خودکار در کمتر از یک دقیقه اگر خطا بود. راه دیگر: نسخهٔ Pro با شرط برگه (افزونه، تأیید).

## ت. کارهای مرورگر برای Cowork

1. Search Console: گزارش صفحه‌ها (Indexed though blocked by robots، Duplicate without canonical، Crawled not indexed)، Core Web Vitals موبایل، و فهرست ۵ مقالهٔ پربازدید ۲۸ روز اخیر (برای اندازه‌گیری دوباره).
2. GTM Preview: تگ‌های فعال، تکرار GA4، Clarity.
3. تنظیمات فلوئنت: هانی‌پات، تأیید یا ریدایرکت هر فرم.
4. وردپرس: «هرکسی می‌تواند ثبت‌نام کند»، ورود دومرحله‌ای مدیرها، وضعیت رمز کمپین در اسنیپت ۵۰۵۰۵۰ (فقط «خالی/نمونه/تنظیم‌شده»، نه مقدار).
5. خروجی ورودی‌های فرم ۱۱ از فلوئنت.
