# درگاه‌های ورودی تجربه

این سند نقشهٔ همهٔ درهای ورودی سایت و بات است: قرارداد ورود، رجیستری دکمه‌ها و طرح رویدادها. چارچوب مرحله‌ها و نرخ‌ها همان اسکیل `tajrobeh-leadflow` است (هشت مرحله: رسیدن، اقدام، لید، تماس اول، ارجاع، معارفه، شروع درمان، ماندگاری). اسم تازه برای مرحله‌ها ساخته نمی‌شود.

**قاعده:** هر صفحه یا کمپین تازه اول در رجیستری (`site/cta-registry.json`) ثبت می‌شود، بعد منتشر می‌شود. site-check روی PR و site-mirror بعد از هر آینه، هر کد start، `data-cta`، فرم یا پارامتر ثبت‌نشده را قرمز می‌کنند.

## ۲. رجیستری دکمه‌ها (`site/cta-registry.json`)

- **codes:** هر کد start ثابت. `code` نام طبق قاعده است و `aliases` کدهای قدیمی‌ای که روی سایت هستند و همچنان کار می‌کنند. `line` خط است و `pages` جاهایی که لینک دارند.
- **families:** کدهای ساختنی با پیشوند ثابت، مثل `mg-` (مجله)، `tm-` (صفحهٔ تیم)، `ebi` (کمپین)، رویدادهای مدرسه (`web_`، `pre_`، `app_`، `cp_`) و دعوت روان‌پزشک.
- **builders:** صفحه‌ها و اسنیپت‌هایی که کد را در اسکریپت می‌سازند. هر کدام یک خط توضیح دارد و بعد با تابع کمکی یکی می‌شوند.
- **forms:** شناسهٔ هر فرم فلوئنت با خط و نام. فرم بی‌ردیف یا بی‌`$map` در 501143 قرمز است.
- **getTherapy:** پارامترهای مجاز `/get-therapy/`. نام تازه `need` و `src` است. `from` و `tj_*` قدیمی‌اند و خوانده می‌شوند. `utm_*` آزاد است.
- **ctas:** شناسهٔ `data-cta` هر دکمه. شکل شناسه: `<صفحه>.<جا>[.<جزء>]`، مثل `home.hero.start`.

**قاعدهٔ نام کد تازه:** `<خط>-<جا>[-<جزء>]` با حروف کوچک لاتین، رقم و «-».

| کد خط | خط |
|---|---|
| `pz` | پذیرش |
| `sch` | مدرسه |
| `psy` | روان‌پزشکی |
| `org` | سازمانی |
| `rm` | رودمپ |
| `cmp` | کمپین |
| `co` | همکاری |

ابزار: `node site/tools/cta.mjs check | scan | selftest`.

## ۳. قرارداد ورود (بند ۱، در راه)

مسیر یکتا: `/wp-json/tj/v1/lead` در سایت ← بات. هر فرم و ویجت فقط از این مسیر می‌گذرد. فیلدهای مشترک:

| فیلد | معنی |
|---|---|
| `line` | خط: پذیرش، مدرسه، روان‌پزشکی، سازمانی، رودمپ، کمپین، همکاری |
| `intent` | نیت |
| `page` | صفحه |
| `cta` | شناسهٔ دکمه |
| `campaign` | کمپین |
| `utm` | UTM |
| `ref` | ارجاع‌دهنده |
| `vid` | شناسهٔ بازدید (کوکی درجهٔ اول) |

## ۴. رویدادها (بند ۵، در راه)

`cta_click` ← `lead_created` ← `intro_booked` ← `intro_done` ← `therapy_started`. این رویدادها هم به آنالیتیکس می‌روند و هم به هاب آمار، با همان شناسه‌ها. پیش از هر تغییر، بیس‌لاین ثبت می‌شود.
