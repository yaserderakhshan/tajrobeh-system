# ورود از اینستاگرام به بات (v168.1)

## کد start

```
https://t.me/tajrobehlife_bot?start=ig_<پیج>_<کلمه>
```

- **پیج:** `tl` برای tajrobeh.life و `ts` برای tajrobeh_school.
- **کلمه:** فقط حروف کوچک انگلیسی، رقم و زیرخط (`_`). فاصله، حرف بزرگ و حرف فارسی پذیرفته نمی‌شود.
- **طول:** کل کد (از `ig_` تا آخر) حداکثر ۶۴ نویسه است. این سقف خود تلگرام است.
- نمونه‌ها: `ig_tl_karaj`، `ig_ts_eft`، `ig_tl_abroad`.

## کلمهٔ تازه، بدون کد

یک سطر به تب «نقشهٔ کلمه‌ها» در هاب تجربه اضافه کنید. تغییر حداکثر تا ۱۰ دقیقه بعد در بات دیده می‌شود.

| ستون | چه بنویسید |
|---|---|
| پیج | `tl` یا `ts` |
| کلمه | همان کلمهٔ داخل کد، مثلاً `karaj` |
| برچسب فارسی | نامی که در دفترها دیده می‌شود، مثلاً «حضوری کرج» |
| مقصد | یکی از مقصدهای جدول بعد |
| نوع درخواست | اگر از کلمه معلوم است، مثلاً «گروه‌درمانی». وگرنه خالی |
| حالت جلسه | «آنلاین» یا «حضوری»، یا خالی |
| شناسهٔ مکان | شناسهٔ تب «مکان‌های حضوری»، مثلاً `karaj2` |
| موضوع | اگر از کلمه معلوم است. وگرنه خالی |
| کد UTM | کد تب «سئو · لینک‌های UTM»، مثلاً `U-226` |

**قاعدهٔ ثابت:** هیچ مقصدی بیرون از اکوسیستم تجربه نیست. پرسلاین، فرم گوگل و مانند این‌ها پذیرفته نمی‌شود. «صفحه» فقط مسیری از tajrobeh.life است و بات نشانی بیرونی را رد می‌کند.

| مقصد | چه می‌شود |
|---|---|
| `تراپی` | خوش‌آمد کوتاه، سؤال موضوع، بعد رزرو معارفه |
| `تراپی خارج` | مسیر فارسی‌زبانان خارج از ایران |
| `مدرسه` | فهرست دوره‌هایی که ثبت‌نام باز دارند |
| `مدرسه:<کد کمپین یا نام دوره>` | لید مدرسه و کارت برای مسئول مدرسه، فقط بار اول. اگر دوره کمپین داشته باشد، کارت دوره هم نشان داده می‌شود |
| `بات:<کد start>` | همان مسیر موجود بات، مثل `ev`، `comm`، `join`، `style`، `test` |
| `صفحه:/<مسیر>` | یک پیام کوتاه با دکمهٔ لینک صفحه‌ای از tajrobeh.life، همراه UTM |
| `بات:mig` | تست تجربهٔ روانی مهاجرت، با همان منبع اینستاگرام |
| `تست‌ها` | منوی «تست‌های تجربه در بات» |
| `خوش‌آمد` یا خالی | خوش‌آمد عادی بات |

کلمه‌ای که در جدول نیست هم کار می‌کند: خوش‌آمد عادی می‌آید و منبعش ثبت می‌شود.

## چه چیزی کجا ثبت می‌شود

- **ورود:** یک سطر در «کلیک‌های تماس» با مسیر `اینستاگرام › بات › …` و خود کد.
- **کاربر:** ستون «ورود اینستاگرام» در تب کاربران بات (کد و تاریخ).
- **لید تراپی:** اگر تا ۳۰ روز بعد از ورود لید ساخته شود، منبع لید «اینستاگرام · پیج · کلمه» است. نوع درخواست، موضوع، منطقه و حالت جلسه هم از همان سطر پر می‌شوند، ولی فقط اگر خالی باشند. جواب خود مراجع همیشه برنده است.
- **لید مدرسه:** ستون «منبع» در «لیدهای مدرسه».
