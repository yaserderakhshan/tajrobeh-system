# برند تجربه

| فایل | چیست |
|---|---|
| `tokens.css` | توکن‌های رنگ، تایپوگرافی، فاصله و شعاع. رنگ و تایپوگرافی از فیگمای Tajrobeh Main استخراج شده؛ فاصله، شعاع و دارک‌مود پیشنهادی‌اند. |
| `fonts.css` و `fonts/` | **در این مخزن عمومی نیستند.** فونت‌های Anjoman مجوز تجاری دارند و بازنشر نمی‌شوند؛ در مخزن خصوصی «Tajrobeh-knowledge» (`brand/`) و روی خود سایت هستند. |

## استفاده در صفحه

```html
<link rel="stylesheet" href="fonts.css">
<link rel="stylesheet" href="tokens.css">
```

## وزن‌ها

| وزن | Anjoman Max (اصلی) | Anjoman | Anjoman Condensed |
|---|---|---|---|
| ۳۰۰ | ندارد | Light | ندارد |
| ۴۰۰ | Regular (فقط woff2) | Regular | Condensed |
| ۵۰۰ | ندارد | Medium | Medium |
| ۶۰۰ | ندارد | SemiBold | SemiBold |
| ۷۰۰ | Bold | ندارد | ندارد |
| ۸۰۰ | ExBold | ندارد | ExtraBold |
| ۹۰۰ | Black | Heavy | Heavy |
| ۹۵۰ | ExBlack | ندارد | ندارد |

پیش‌فرض همیشه Anjoman Max است. Anjoman Condensed فقط برای تیتر یا برچسبی است که در جای تنگ جا نمی‌شود. این خانواده‌ها نسخه‌های متفاوت یک فونت‌اند و طراحی حروفشان کمی فرق دارد، پس هر کدام با نام خودش بارگذاری می‌شود.

## مجوز

تجربه مجوز استفادهٔ تجاری از فونت انجمن را خریده است، از جمله برای سایت tajrobeh.life.
