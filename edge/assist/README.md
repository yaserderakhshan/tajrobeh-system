# ورکر دستیار تجربه (tj-assist)

موتور پاسخ زندهٔ دستیار سایت، روی ورکر کلادفلر. هیچ پرسشی در مسیر کاربر به اپس‌اسکریپت نمی‌رود.

| مسیر | کار |
|---|---|
| `POST /assist` | قرارداد `assist.ask` (پل نسخه ۲). مرورگر سایت با مبدأ tajrobeh.life، یا سرور با امضای `ts` و `sig` |
| `GET /assist/boot` | جملهٔ شروع، چهار پرسش پرتکرار، موضوع‌ها، جملهٔ حریم خصوصی |
| `GET /assist/near?q=` | سه موضوع نزدیک، بی گزارش (بازگشت سبک ویجت) |
| `POST /assist/refresh` | بات بعد از تأیید دانش و تعویض نمایه صدا می‌زند؛ دقیقه‌ای یک بار |
| `GET /assist/health` | نسخه و سن داده، بی محتوا |

- **داده:** اکشن درگاه `as_dump` بات (ردیف‌های تأییدشده، نمایهٔ سایت، رویدادها، واژه‌ها و پیام ثابت بحران) در KV `tj-assist`؛ هر ۳۰ دقیقه و با پینگ بات تازه می‌شود.
- **ترتیب پاسخ:**
  1. بحران، بی هیچ سرویس بیرونی؛
  2. «وضعیت من» فقط در تلگرام؛
  3. ابزار رویدادها و مجله؛
  4. دانش تأییدشده؛
  5. متن منتشرشدهٔ سایت با «بیشتر بخوانید»؛
  6. سه موضوع نزدیک و «با پذیرش حرف بزنم».
- **جمنای:** فقط روی پاسخ از سایت، فقط با `ASSIST_REWRITE` و `GEMINI_API_KEY`، با پرسش پاک‌شده، مهلت ۲٫۵ ثانیه و سقف روزانه. خروجی با عدد، لینک یا نام تازه، یا حرف از «متن‌ها»، رد می‌شود.
- **گزارش:** با `ctx.waitUntil` و اکشن `as_log`؛ کاربر منتظر نمی‌ماند. متن پرسش فقط برای بی‌پاسخ‌ها می‌رود، پاک‌شده.
- **انتشار:** گردش کار `assist-edge.yml`. آزمون: `node --test 'edge/assist/test/*.test.mjs'`؛ آزمون دود: `node edge/assist/smoke.mjs <نشانی>`.
