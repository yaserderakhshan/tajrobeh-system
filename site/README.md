# site

کد و قالب‌های سایت tajrobeh.life. پیش از انتشار، قواعد `CLAUDE.md` را چک کن: بدون خط تیره وسط جمله، بدون اطلاعات شخصی بی‌اجازه، بدون شرایط مالی.

سایت زنده مرجع اسنیپت‌ها، برگه‌ها و قالب‌هاست. Cowork روی سایت کار می‌کند و بعد از هر ویرایش site-mirror را صدا می‌زند؛ site-mirror هر ساعت هم خودش اجرا می‌شود. site-deploy اگر سایت جلوتر باشد می‌ایستد. آفر کمپین فقط داخل هیرو و داخل طراحی صفحه.
