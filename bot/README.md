# bot

کد بات تلگرام مرکز تجربه زندگی (پروژهٔ Apps Script «Tajrobeh Webhook»). توکن‌ها و رمز وبهوک فقط در Script Properties هستند.

دیپلوی خودکار است: مرج روی شاخهٔ اصلی که این پوشه را عوض کند، گردش کار `.github/workflows/bot-deploy.yml` را اجرا می‌کند. از v166.8: اول همهٔ تست‌ها با دادهٔ ساختگی بی‌اتصال به گوگل (`node .github/scripts/bot-precheck.mjs`، روی هر PR هم)، بعد clasp push با توقف کارهای زمان‌دار، نسخهٔ تازه روی دیپلوی آزمایشی و اجرای همهٔ تست‌ها آنجا، و فقط اگر همه سبز بود انتشار روی همان دیپلوی اصلی. بعد ۶۰ دقیقه پایش تب «خطاها». هر قرمزی = برگشت خودکار به نسخهٔ قبل و PR معکوس. `.clasp.json` شناسهٔ پروژه را نگه می‌دارد. شرح کامل در اسکیل `tajrobeh-bot` بخش ۱۶.

مسیر انتشار، شمارهٔ نسخه (`bot/version.gs`)، `CHANGELOG.md` و نقشهٔ کوتاه (`docs/bot/MAP.md`): بخش ۱۱ `CLAUDE.md` و بخش ۱۶ اسکیل بات.

**انتشار و اطلاع‌رسانی مجله (از v167):** مسیر رسمی «درگاه انتشار» است (`bot/publish.gs`، راهنما: `docs/publish-api.md`). `maintRun` و هر اجرای دستی در ویرایشگر برای انتشار به کار نمی‌رود.
